# MapTiles common API audit

> **Review status: boundary audit, 2026-08-07. Promotion decision: none.**
> Phase 1 currently fails its corpus go criterion. This report freezes the spike
> API in its existing modules; it is not compatibility or host-conformance
> evidence and does not authorize more MapTiles work.

## Method and decision rule

This audit inventories every public common declaration introduced by the
MapTiles spike in `map-runtime`, plus the two generic declarations it exercises
in `extension-catalog` and `normalized-ir`. “Fake evidence” below identifies a
deterministic test subject, not a reviewed passing execution report. Per
[ADR-0001](decisions/0001-ir-ownership.md), only resolved, language-neutral
operations belong in NIR. Per [ADR-0003](decisions/0003-runtime-host-boundary.md),
target handles and nondeterministic services stay behind capability adapters.

No declaration is moved into a more central module by this audit. A declaration
marked “generally applicable” is only a candidate: promotion requires a second
representative capability, Phase 1 conformance, lifecycle/disposal fixtures, and
a reviewed API decision. URLs, credentials, DOM, MapLibre, promises, WebGL, and
renderer behavior remain forbidden in source model, NIR, runtime core, and the
extension catalog.

## Map value, command, event, and query contracts

All declarations in this section remain in **`map-runtime`**. None belongs in
the project source model, generic NIR, runtime core, or extension catalog merely
because the demo consumes it.

|---|---|---|---|---|---|---|---|---|
| `GeoCoordinate` | Authoritative longitude/latitude for cameras, clicks, projection, and markers. | Geographic/map-specific value; **map runtime**. | Numeric degrees only; no host leak. | Boundary and projection round-trip test subjects use fixed arithmetic. | Without the map capability, operations carrying it are rejected before host use. | Immutable; no disposal. | GPS/geofencing could reuse the mathematical value, but that is not evidence to centralize it. | Retain locally. |

| `GeoElevationMode`, `GeoAnchorVisibility`, `MapAnimationEasing` | Controls ground/altitude retention, marker visibility, and deterministic geo interpolation. | Map/overlay-specific policy; **map runtime**. | No target leak; names encode semantic policy rather than renderer implementation. | Seeded-clock animation and visibility/projection test subjects exercise values. | Headless rejects the containing host operation; portable animation can run without rendering. | Values are immutable; cancellation is handled by animation state/runtime. | Generic animation might share easing mathematics, but its timing/ownership contract must be independently proven. | Retain locally. |

| `MapSourceId`, `MapLayerId`, `MapOverlayId` | Stable identities for visibility, feature filters, and logical markers. | Map-specific IDs; **map runtime**. | Plain strings; IDs must never contain credentials or target handles. | Ordered maps and fixed query records use these IDs in test subjects. | Host operations fail without a map host; IDs alone have no effect. | Adapter clears owned overlays/listeners at disposal; source/layer IDs are non-owning. | Other capabilities need their own typed IDs rather than erasing domains to strings. | Retain locally. |

|---|---|---|---|---|---|---|---|---|
| `MapHostLifecycle` | Makes initialization readiness and terminal disposal explicit. | Lifecycle states are generally recognizable, but this enum is a map-host contract in **map runtime**. | No target leak. | Fake host rejects invalid lifecycle calls, makes repeated disposal successful, and stops callbacks. | No host is represented by capability rejection, not a fake `NEW` map host. | `NEW → INITIALIZING → READY → DISPOSED`; initialization is once-only; disposal is terminal/idempotent, cancels animation, releases handles, and stops events. | Audio, networking, and render hosts need lifecycle contracts, but may need different states. | Retain locally until another capability validates a common state machine. |

| `MapOverlayAnimationStatus`, `MapOverlayAnimationState` | Stores replace-active marker interpolation including start/end, elapsed game time, current coordinate, easing, and completion state. | Map-overlay state; **map runtime**, not NIR or host adapter. | Fully serializable; no target leak or renderer frame. | Seeded samples prove deterministic coordinates in test subjects, including antimeridian and replacement cancellation. | Runs headlessly as pure portable state; any subsequent render request rejects without capability. | Starting a replacement cancels the active state; scene/runtime disposal must cancel and clear all owned states. | Generic tweening is plausible, but coordinate wrapping and overlay ownership are map-specific. | Retain locally. |

## Boundary findings and work freeze

1. **No leak was found in common signatures.** Browser/MapLibre/DOM/WebGL types
   appear in `maplibre-js-host`, not in the audited common contracts. Common
   JSON feature snapshots and `suspend` functions are not JavaScript promises or
   target handles. This is a static finding, not host conformance.
2. **Two generic abstractions are appropriately central today:** stable
   `RuntimeCapabilityId` catalog metadata and resolved `ExtensionHostOperation`
   NIR. Their placement follows the accepted ADRs; the MapTiles spike does not
   justify expanding their surface.
3. **Potentially general APIs are not promoted:** `MapRuntimeClock`,
   `MapHostResult`, lifecycle states, event queues, and trace separation need a
   non-map capability comparison and passing Phase 1 evidence first.
4. **All remaining APIs stay map-specific.** Similar data-class shapes are not
   sufficient evidence for runtime-core ownership.
5. **Work is paused.** Until the Phase 1 go criterion passes, do not add MapTiles
   authoring features, tile-provider integrations, style editing, offline
   support, terrain, native rendering, or production packaging. Maintenance
   needed to preserve isolation or correct a gate failure is allowed; feature
   expansion is not.
